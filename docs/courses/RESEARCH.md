Examples with names, projects or measurements are fictional unless explicitly stated otherwise. Coaches should review the drafts before publication.

## Course map

Six courses, four lessons each. First lessons are free; later lessons use the existing `courses.allLessons` feature. The introduction follows the same rule. All lessons include an explanation, a worked example, a concrete exercise and a review criterion. Reading estimates exclude exercises and field/project work.

| Course | Student leaves with |
| --- | --- |
| Your career, with direction | A target hypothesis, evidence map and two-week plan |
| A resume that shows your work | A truthful, tailored resume checked after export |
| LinkedIn, with a clear story | A consistent profile, evidence links and a personal outreach draft |
| GitHub that speaks for itself | Curated repositories, reproducible documentation and a contribution plan |
| Build something that matters | A narrow, tested project and a case study with limitations |
| Don't be square | A domain field guide, a conversation reflection and a small experiment |

## Decisions and limits

- Practical quantities (three postings, two-week cycles, a few conversations) are suggested exercise sizes, not research-established thresholds for getting hired.
- The courses support preparation. Personalized coaching stays with Wasif and Abishek; there is no AI coach or assessment service.
- Do not fabricate outcomes, recommend mass messages, harvest personal data, manufacture GitHub activity or guarantee ATS/recruiter outcomes.
- Hobbies and community experience count. Activities offer free, remote and small-scale alternatives; expensive travel and unpaid professional work are not prerequisites.
- Progress is optional, browser-local demo state. It is self-reported, can be undone and does not award a verified credential. No database, auth or payment integration is part of this task.
- Delivery is local-only on `page/courses`, based on `dashboard`. Wasif requested no commit, push, PR or merge before local review.
