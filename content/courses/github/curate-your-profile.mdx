## Give a visitor a useful starting point

Someone opening your GitHub profile should be able to find work you understand and can explain. Choose a few repositories that show different strengths: a useful application, a careful data experiment or a contribution to a shared project. More repositories are not automatically more informative.

Use a short profile README if it helps provide context. GitHub supports one through a public repository matching your username with a README file at its root. Explain what you are exploring and which work a visitor should open first. Pin the repositories that support that explanation. Revisit the selection when your strongest work changes.

Keep learning experiments if they are useful to you. Label tutorials and forks clearly; do not present another person's implementation as your original work. Before making a repository public, check for credentials, private data and material you do not have permission to share.

## A worked example

Maya pins a class inventory API and a small text-search experiment. Each description explains purpose rather than only listing languages. Her profile says she is learning backend engineering and points to a README that describes her contribution to a team project.

She leaves a tutorial labeled as a learning exercise. Her public activity has gaps during exams. The contribution graph reflects GitHub activity under platform rules; it does not directly measure skill, effort in private work or readiness for a role.

## Your turn · 25 minutes

1. Review your repositories for ownership, sharing permission and sensitive content.
2. Choose two or three you would be comfortable explaining.
3. Give each a purpose-driven description and check the README.
4. Draft a short profile introduction and pin your chosen work.

**Leave with:** a navigable profile and a review list. Ask someone to find your strongest project without instructions. Do not manufacture commits to color the activity graph. Useful work, clear context and honest ownership are better goals for this exercise.
